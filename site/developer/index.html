Seven chapters for the developer who provides a spec, pins a dependency and wires both into a build. They assume the Concepts page.

  • Chapter 1

    The web UI

    Producers, the spec viewer with diff and blame, Consumers, the graph, the reports.

  • Chapter 2

    sanshain.yaml

    The one file every client reads: provides, requires with exact pins, the catalog push.

  • Chapter 3

    Clients

    Maven, cargo, Go, JavaScript with its GitHub Action, Conan: install and commands.

  • Chapter 4

    API lifecycle

    Snapshots, GA, the proposed next version, deprecation, AsyncAPI message contracts.

  • Chapter 5

    Release graphs

    Trunk and the main graph, cutting a sanshain-branch, hotfixes by tag, the timeline.

  • Chapter 6

    CI integration

    Tokens, stability and streams from the pipeline, dry runs, idempotency, examples.

  • Chapter 7

    MCP for AI assistants

    A read-only token, the endpoint, client configuration, the seven tools, the limits.

The REST contract itself is the REST API reference, and Using the API explains tokens, scopes and error shapes. Webhook receivers, deployment and administration are still the Markdown guides on GitHub (deployment, administration, webhooks) until the Operator chapters land.

Checked against v2.6.0.

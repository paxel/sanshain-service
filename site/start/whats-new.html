2.12.0 is a maintenance and security release: every library is on its current version and three security advisories are gone. It adds no feature. This page is the short version of the changelog, sorted by who notices a change.

Before you upgrade

One change can stop a working setup: the OpenID Connect login refuses a provider whose key set (jwks_uri) is served over plain http. Serve it over https; a provider behind a private CA needs that CA in EXTRA_CA_CERTS_DIR (Additional CA certificates). Local accounts and LDAP are not affected.

For operators

  • The image is based on Alpine 3.24 instead of 3.21, and its health check asks 127.0.0.1, so a container where localhost resolves to IPv6 first is no longer reported unhealthy.
  • Webhook deliveries and the OIDC login trust the platform's certificate authorities plus EXTRA_CA_CERTS_DIR, like LDAPS, instead of a list built into the binary.
  • Releases are signed with cosign 3; verify them with cosign 3, or with cosign 2.6 and --new-bundle-format (Verifying a release).
  • The Helm backup CronJobs use curl 8.23.0 and pg_dump 18, which also backs up a PostgreSQL 18 database; restore those dumps with pg_restore 18.
  • OpenTelemetry exports retry a failed send up to 3 times instead of dropping the batch.
  • SQLite 3.51 is built in instead of 3.46; an existing database opens unchanged.

For Producers and Consumers

  • Endpoint snippets and required specs are written in a slightly different YAML style: double quotes, quoted version strings (version: "1.0.0"), long single-line texts folded with >. Their content is the same. A Consumer that commits a required spec sees a one-time text diff after the upgrade.
  • An unchanged re-provide is still a no-op. The first re-provide of a snapshot that changes anything counts all its endpoints as updated once.
  • A spec nested deeper than 64 levels is refused with 400; the limit was 128.
  • The official clients need no update for 2.12. Their current releases (sanshain-js 2.5.1, sanshain-rs 3.2.0, sanshain-go 2.4.0, sanshain-maven-plugin 2.4.1, sanshain-conan 2.4.0) are dependency and security updates too.

Security

  • YAML is read and written by serde-saphyr, pure Rust without unsafe code, instead of a library on the unmaintained unsafe-libyaml.
  • The OIDC login verifies ID tokens without the rsa crate (Marvin attack, RUSTSEC-2023-0071); cargo audit runs without exceptions.
  • The unmaintained basic-toml is no longer part of the build.

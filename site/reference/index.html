The two tables

The tables an operator looks up most live in the Operator track, next to the prose that explains them, and each is held in step with the code by a test:

  • Environment variables: every variable the service reads, with its default and effect. A cargo test fails when the service reads a variable the table does not list, or the table lists one the service does not read.
  • Permissions: the ten permissions, what each allows and which roles hold it. A cargo test fails when the table and the Permission enum disagree.

The contracts themselves

The sources of the generated pages are api.yaml and maintenance.yaml on GitHub, both OpenAPI 3.0.3 documents that a code generator can consume. The architecture decision records are in docs/adr.

Common Troubleshooting Tips:

  • Ensure the Server URL is correct (e.g., ldap://hostname:389 or ldaps://hostname:636).
  • Check if the Bind DN and Bind Password are correct.
  • Verify that the Sanshain service can reach the LDAP server (check firewalls/network).
  • For User Filter, typically (uid={username}) or (sAMAccountName={username}) is used.
  • If using ldaps://, ensure the server certificate is trusted or matches the hostname.
